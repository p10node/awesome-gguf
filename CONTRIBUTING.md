# Contributing to Awesome GGUF

Thank you for your interest in contributing to **Awesome GGUF**! We welcome submissions of tools, runtimes, bindings, educational resources, and guides that empower the local AI community.

---

## 📋 Submission Guidelines

To keep this list high-quality and reliable for everyone, please ensure your contribution adheres to the following criteria:

1. **Active Maintenance:**
   - The repository or project must be actively maintained (recent commits within the past 6 months).
   - Deprecated or abandoned projects will be pruned.
2. **Direct Relevance:**
   - The project must directly support, implement, or interact with the **GGUF** binary format or its surrounding ecosystem (`llama.cpp`, `ggml`).
3. **Quality & Documentation:**
   - The repository must have a clear `README`, proper installation instructions, and an open-source license.
4. **Formatting & Ordering:**
   - Format entries as: `- **[Project Name](https://url)** — Brief, objective description.`
   - Place your entry in **alphabetical order** within the most appropriate category.
   - Avoid marketing buzzwords or superlative claims (e.g., avoid "the best ever", "revolutionary").

---

## 🚀 How to Submit a Pull Request

1. **Fork** this repository.
2. Create a new branch for your change:
   ```bash
   git checkout -b add-my-project
   ```
3. Update both `README.md` (English) and `README.vi.md` (Vietnamese, if applicable).
4. Commit your changes with a descriptive message:
   ```bash
   git commit -m "Add <ProjectName> to <Category>"
   ```
5. Push to your fork and submit a **Pull Request**.

Thank you for helping make local AI accessible to everyone!
